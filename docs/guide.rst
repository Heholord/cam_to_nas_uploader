Usage Guide
===========

Photo Transfer Workflow
-----------------------

1. Prepare your photos in SOURCE_FOLDER
2. Run the script:

   .. code-block:: python

      python photo_transfer.py

3. Check the log file for results

Configuration
-------------

Edit these variables in the script:

.. code-block:: python

   MEDIA_PATH = "/media/manuel/Media"
   SOURCE_FOLDER = "."
   dryrun = False
